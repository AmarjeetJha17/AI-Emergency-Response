# EmergencyResponse.LoadTests

This NBomber runner is intended for isolated local development and non-production staging. It has deterministic fake AI/search/weather/storage services and refuses a local SQL database unless its name contains `LoadTest`.

See [load-testing.md](../../docs/testing/load-testing.md), [chaos-testing.md](../../docs/testing/chaos-testing.md), and [performance-gates.md](../../docs/testing/performance-gates.md) for setup, profiles, run safety, and interpretation.
