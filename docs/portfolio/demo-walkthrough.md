- Confirm the API started against the intended local database and check `/health/ready` at `https://localhost:7191/health/ready`, then sign in at `https://localhost:7201/Account/Login`. Development and Test API startup apply pending EF migrations before seeding; review and back up retained databases before launching. Production does not auto-migrate.
- Use an existing synthetic Citizen only to show the report form; use an existing Operator or SystemAdmin for operations. Keep separate browser profiles or sign out when switching roles. Do not create or mutate a new fixture for the talk unless you have an isolated disposable copy and an approved cleanup plan.
- Check the latest [feature verification](feature-verification.md) and [UI verification](ui-ux-verification.md). The existing screenshot set predates the latest UI polish and does not replace a current visual check.
- Turn off screen notifications and inspect the browser window for secrets or personal data before screen sharing. Keep provider mode explicit. The current fixture set does not include generated AI output.
